<h1 align="center">ReMind on Lucid</h1>

<p align="center"><b>Out-of-sight dynamic memory for causal video generation, natively on Apple Silicon.</b></p>

A torch-free re-implementation of [ReMind](https://github.com/Applied-Intuition-Open-Source/ReMind)
(arXiv 2605.25333) on [Lucid](https://github.com/lucid-official/lucid). Work in progress: the port
is being built milestone by milestone; see `docs/PORTING_PLAN.md`.

Code and weights are for non-commercial use only (CC BY-NC 4.0, see `LICENSE` and `NOTICE`).
